対象

actuator は開発者が自分ひとりで使う個人用のアプリです。Google のアカウントを接続するのも、ブラウザの拡張機能を登録するのも開発者本人だけで、ほかの人のデータは扱いません。

Google から受け取るデータ

許可の範囲は https://www.googleapis.com/auth/calendar.events.readonly（予定の読み取りだけ）です。Google Calendar API から、次の項目だけを受け取ります。

  • 予定の ID、題名、開始と終了の日時
  • 予定の状態（確定・仮・取り消し）、予定の種類、「予定あり／予定なし」の区別
  • 本人の出欠の返事（参加しない予定を表示しないため）

予定の説明、場所、ほかの参加者の名前やメールアドレスは受け取りません。

使い方

受け取った予定は、actuator の予定の画面に表示するためだけに使います。広告、ほかの目的での分析、AI モデルの学習には使いません。

保存と管理

  • 予定のデータは保存しません。画面の表示のたびに Google から取得し、応答を返した後は残しません
  • Google の接続の鍵（refresh token）は、開発者が管理する Cloudflare Workers の暗号化されたシークレットにだけ保管します。短い期限の鍵（access token）は、サーバーのメモリにだけ一時的に置きます
  • 鍵や予定の題名をログに記録しません

第三者への提供

受け取ったデータを第三者に提供・販売しません。処理には Cloudflare Workers を使います。

Google API サービスのユーザーデータに関するポリシー

actuator が Google API から受け取った情報の使用と移転は、限定的使用の要件を含め、Google API Services User Data Policy に従います。

アクセスの取り消し

Google アカウントのサードパーティとの接続 から、いつでも actuator のアクセスを取り消せます。取り消すと、actuator は予定を読めなくなります。

ブラウザの拡張機能

actuator のブラウザの拡張機能（Chrome ウェブストア・Edge アドオン）は、開発者本人の予約の間に、本人が決めたサイトを開けないようにするための道具です。

  • 扱うのは、登録のトークン、本人が指定した actuator のサーバーの URL、そのサーバーから受け取る予約と止めるサイトの一覧だけです。どれもブラウザの中（chrome.storage.local）にだけ置きます
  • 通信するのは、登録のときに本人が指定した actuator のサーバーだけです。トークンはそのサーバーへの問い合わせにだけ使います
  • 閲覧の履歴、開いたページの URL や中身、入力した文字は集めず、どこにも送りません。止めた・開けなかったという記録も送りません
  • 広告・分析・第三者のサービスは使いません
  • 拡張機能を外すと、ブラウザの中に置いた情報はすべて消えます

Privacy Policy

actuator / Effective: October 15, 2026 / Updated: October 17, 2026 (browser extension added)

Scope

actuator is a personal app used only by its developer. Only the developer connects their own Google account and pairs the browser extension; no other person's data is handled.

Data received from Google

The only scope requested is https://www.googleapis.com/auth/calendar.events.readonly. From the Google Calendar API, actuator receives only:

  • Event ID, title, start and end time
  • Event status, event type, and whether the event is marked busy or free
  • The user's own response status (to hide declined events)

Event descriptions, locations, and other attendees' names or email addresses are not requested.

Use

Event data is used only to display events on actuator's schedule screen. It is not used for advertising, unrelated analytics, or training AI models.

Storage

  • Event data is not stored. It is fetched from Google for each display request and discarded after the response is returned.
  • The refresh token is kept only as an encrypted secret in Cloudflare Workers managed by the developer. Short-lived access tokens are kept only in server memory.
  • Tokens and event titles are not written to logs.

Sharing

Data is not shared with or sold to third parties. Processing runs on Cloudflare Workers.

Google API Services User Data Policy

actuator's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account third-party connections.

Browser extension

The actuator browser extension (Chrome Web Store and Edge Add-ons) blocks sites chosen by the developer during the developer's own scheduled work blocks.

  • It handles only a pairing token, the URL of the actuator server specified by the user, and the schedule and blocked-site list received from that server. All of these are kept only inside the browser (chrome.storage.local).
  • It communicates only with the actuator server specified at pairing. The token is used only for requests to that server.
  • It does not collect or transmit browsing history, visited URLs, page content, or typed input. It does not report blocking events.
  • It uses no advertising, analytics, or third-party services.
  • Removing the extension deletes all data it stored in the browser.
